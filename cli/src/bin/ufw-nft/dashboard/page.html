Investigation

a full incident dossier for any source — built from what this host observed, and nothing it didn't
What an investigation can — and can't — tell you
This dossier is assembled entirely from this host's own firewall logs plus a reverse-DNS (PTR) name lookup. It shows every packet the source sent here, when, to which ports, and which rules it tripped — enough to contain the source and file an abuse report with its network. It deliberately does not scan or connect back to the attacker's machine, and it does not claim to identify the person behind an address — an IP is not a person, and probing someone else's host or de-anonymizing them would be both unreliable and unlawful. Attribution is left to the source's network operator, whom the abuse report is addressed to.

Network manager

devices sharing this host's local network
What this shows — and what it can't
Every device on this host's local network, and the service ports each one leaves open — how you find the forgotten device, the unexpected open service, the thing that shouldn't be here. It reports only what a device answers on the network; it does not show what a person is doing inside their device (their screen, apps, or browsing) — that would require intercepting their traffic or software on their machine, which this does not do. Only this host's own directly-connected subnet is ever scanned.
